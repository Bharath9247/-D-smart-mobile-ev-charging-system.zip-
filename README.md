# Smart Mobile EV Charging System

## Project Overview
The Smart Mobile EV Charging System is a web-based application designed to help electric vehicle (EV) users request mobile charging services at their location. It provides interfaces for users, administrators, and drivers to manage charging requests and service operations.

## Objectives
- Simplify access to EV charging services.
- Allow users to request mobile charging assistance.
- Help drivers manage charging requests.
- Enable administrators to monitor users, drivers, and service activity.

## Technologies Used
- **Programming Language:** Python
- **Backend:** Flask
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **Version Control:** Git and GitHub

## Key Features
- User registration and login
- Mobile charging service requests
- Driver dashboard and request management
- Administrator dashboard
- Charging request tracking and history
- Charging price and service management

## Installation and Execution

1. Install Python 3.10 or a compatible version.
2. Clone this repository:
   ```bash
   git clone https://github.com/Bharath9247/-D-smart-mobile-ev-charging-system.zip-.git
   ```
3. Open the project directory:
   ```bash
   cd -D-smart-mobile-ev-charging-system.zip-
   ```
4. Install dependencies:
   ```bash
   pip install -r smart-ev-charging/requirements.txt
   ```
5. Follow the configuration instructions in the project's `.env.example` file and README inside `smart-ev-charging`, if applicable.
6. Run the application using the project's configured startup instructions.
